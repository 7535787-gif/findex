Асинхронне програмування в Python

asyncio надає цикл подій для конкурентного виконання корутин. Ключові поняття: async def, await, TaskGroup, Semaphore та Queue. Асинхронний код ефективний для мережевого введення-виведення, але блокувальні CPU-операції не можна виконувати безпосередньо в циклі подій.
